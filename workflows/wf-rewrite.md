# WF 改写 —— 把既有文本改成江南腔（v0.2 已可用）

> 前置：已读 `SKILL.md` 路由确认 B 模式；`style/01,02` 已读。

## Step 0 · 定级

1. 对原文跑 `python scripts/audit_style.py <原文>`，保存报告；
2. 按 `rewrite/01-surgery-levels.md` 判级（默认 L2）；
3. 用户没说强度 → 用默认并告知；用户点名"润色/重写" → 按其说法映射级别。

## Step 1 · 锁定不可变清单

按 `rewrite/02-preserve-meaning.md` 提取：全部专名、数字、观点句、结构承诺。落成清单（这段不许丢）。

## Step 2 · 分级手术

- **L1**：按 `rewrite/03-ai-tells.md` 的检索式逐类清词，A→C→F→D→B→E 顺序；不动结构。
- **L2**：逐段重铸——每段先提信息点清单，重写表达层，每 3 段做一次保意核查。
- **L3**：信息点总清单交用户确认后，改走 `wf-generate.md` 全流程。

## Step 3 · 量化验收

```bash
python scripts/audit_style.py <产出>   # 12 项指标必须大面积进入目标区
python scripts/diff_style.py <原文> <产出>   # 维度级对照（v0.5 提供；缺省时用 audit_style 前后两份报告人工对照）
```

- 原文指标在容忍区内的项，改写后**不许跌出**（改写不能把对的改错）；
- 原文超界的项，产出必须归位或写入报告说明。

## Step 4 · 报告与红线

1. 按 `rewrite/04-diff-report.md` 出人读版报告；
2. `overlap_check.py` 过一遍（有本地语料时）；
3. 铁律自检 1–8 逐条确认；
4. 交付 = 产出文本 + 报告，缺一不可。

## 失败模式速查

| 症状 | 病根 | 处方 |
|---|---|---|
| "改完像 AI 写的江南腔" | 只清了词没调节奏（E 类） | 重跑 Step 3，看 M1/M2/M3 |
| "意思变了" | 跳过了 Step 1 清单 | 回 Step 1，重新逐段核对 |
| "比原文还差" | 对原文在容忍区内的项动了刀 | 回退，只动超界项 |
| "风格对但读着假" | 用户原文的场景逻辑本身不成立 | 如实告知：改写救不了结构，建议 L3 |
