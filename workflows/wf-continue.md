# WF 续写 —— 接着上文往下写

> 前置：已读 `style/01,02`，已拿到用户提供的上文。**续写的核心风险不是写得不新，而是写得不像同一篇。**

## Step 0 · 上文指纹提取（必做，不许跳）

对上文跑一遍审计，把"这一篇自己的"参数固化下来——不是对照江南的平均值，是对照**它自己**：

```bash
python scripts/audit_style.py out/上文.md --json
```

提取并记成一张锁定表（后续每一段写完都回头对一次）：

| 锁定项 | 取值来源 | 漂移后果 |
|---|---|---|
| 人称与视角 | 上文原文 | 混用第一/第三人称，读者立刻出戏 |
| 时态基调 | 回忆 / 顺叙 / 双线 | 从顺叙突然跳回忆不设标记，时间线断裂 |
| 对主角的称谓 | 数上文出现频次（大名/绰号/小名） | 同一人三种叫法，像三个人 |
| 段落呼吸 | 单句成段比例、平均句长 | 上文短促、续写变绵密，读起来像换人写 |
| 对话代词系统 | "说" vs "道" 的使用场域 | 古风段突然冒出"他说"，语感塌 |
| 时间锚点 | 上文最后一个时间标记 | 上文是深夜，续写默认到白天 |

## Step 1 · 接续点判定

先判断上文断在哪，再决定怎么接：

- **断在半句/动作中**（"他伸手去够那扇门"）→ 直接续动作，不重述，不总结。
- **断在场景结束**（"然后他走了"）→ 可切镜头，但第一次切必须给时间或空间信号（"第二天""三站路之后"）。
- **断在情绪高点**（"他终于明白了一件事"）→ **不许立刻解释那件事是什么**。先给一个具体反应（去吃了碗面 / 给人打了个电话），把答案往后压一到两段。这是江南最常用的接法。

## Step 2 · 写（忌三件事）

1. **忌前情提要**：不写"回想起刚才发生的一切"。读者刚读完，不需要复述。
2. **忌参数漂移**：句长、单句成段比、对话行占比三项，允许在 `09-dna` 容忍区间内浮动，**不许越过原文自身的 ±20%**。
3. **忌人物走形**：配角只能按上文已给的来历与私心行动；没有来历的配角，续写时给它补一句来历，不要直接推剧情。

## Step 3 · 合并审计（把上文与续文接起来看）

```bash
cat out/上文.md out/续文.md > out/合并.md
python scripts/audit_style.py out/合并.md
python scripts/diff_style.py out/上文.md out/续文.md
```

看 `diff_style` 的「句长」「单句成段」「对话行占比」三项：**若这三项在续文里显著位移，就是换人写的味道**，定点改回。另外看字数比例：续写篇幅一般与原请求匹配（用户说"再写一千字"就写一千字上下 15%）。

## Step 4 · 交付

正文 + 三行说明：接续点判定（断在哪 / 怎么接的）· 参数漂移检查结果 · 是否新增了上文未出现的人物或设定（新增要显式告知）。

## 常见失败模式

| 症状 | 病根 | 处方 |
|---|---|---|
| "读起来像另一篇" | 没做 Step 0 锁定表 | 回去把六项锁定，重写开头一段 |
| "啰嗦，重复前文" | 忌 1 破了 | 删掉所有"刚才/之前的"复述句 |
| "接得顺但没劲" | 情绪高点被立刻解释 | 把答案后压，中间插一个具体动作 |
| "人物说的话不是他会说的" | 只对了剧情没对声纹 | 读上文该角色的三句台词，抓口癖再写 |
