# WF 同人 —— 默认关闭，需前置合规确认

> 触发条件：用户点名要写《龙族》《九州·缥缈录》等江南作品的人物/世界观衍生故事。
> **默认关闭**：用户只是要"少年感""学院奇幻"时，走 `wf-generate.md`，不进入本流程。
> 本流程第 0 步不可跳过、不可简化、不可由模型自行默认"用户已经同意"。

## Step 0 · 前置合规确认（强制）

原文照搬 `references/guardrails/fanfic-policy.md` 第 0 步的四行确认，展示给用户，**等用户回复"确认"后才继续**。用户不确认 → 停止，改为提供"原创同类型故事"（换人名、换世界观，走 A 模式）。

## Step 1 · 风险分级

按 `fanfic-policy.md` 的风险表判定本次请求落在哪一级：

- **低**（日常向、不涉原作核心冲突）→ 正常产出
- **中**（用原作核心设定/世界观机制）→ 产出 + 文首标注出处，限非商用
- **高**（OOC 丑化、擦边、政治化改编、洗白反派暴行）→ **拒绝产出**，说明理由，不解释到可被绕过的程度

## Step 2 · 人物一致性表（写前必建）

| 人物 | canon 声纹（口癖/说话长度/敬语层级） | 行为逻辑 | 本次改动 | 是否标注 AU |
|---|---|---|---|---|
|  |  |  |  |  |

规则：

- 声纹栏必须来自**可观察特征**（说话爱用短句、爱反问、称呼他人用绰号），不许写"性格开朗"这类无法转化为文字的描述；
- 本次改动栏非空时，文首必须写"AU / 若线"声明；
- **canon 角色不逐字复用原作台词**，最长引用 ≤15 字且全文 ≤3 处（与 `copyright.md` 同一机械标准）。

## Step 3 · 写（转 A 模式，附加四条）

进入 `wf-generate.md` 的 Step 1–4，但额外强制：

1. **新增角色承担主要推进**：OC 或 canon 边缘角色推动情节，避免把原作主角写成提线木偶；
2. **世界观只借用公开设定层**（势力名、地名、能力体系名），**不复制原作的描写段落与独有措辞**；
3. **不写原作关键情节的重演**（重写名场面 = 高风险，容易变成逐句改写）；
4. 情绪处理仍守 `style/06`，不因为"是同人"就放纵煽情。

## Step 4 · 交付附加项（缺一项不算交付）

1. 文首标注块：

```
【非官方同人】原作：《…》 原作者：江南
本作品为非商业性二次创作，与原作者及版权方无关，不代表原作立场。
创作者：（用户署名） 性质：同人 / AU（如适用）
```

2. `overlap_check.py` 跑一遍，确认与本地语料的公共片段 **<15 字**；
3. 说明本次用到的 canon 设定清单（让用户能自己核对边界）。

## Step 5 · 商用请求的一律处置

用户提出付费、带货、投稿变现、平台签约等任何商用意图时：**停止产出**，说明衍生作品商用需权利人授权，本 skill 不提供规避授权的协助。已产出的内容不得由本流程背书为"可商用"。

## 常见失败模式

| 症状 | 病根 | 处方 |
|---|---|---|
| 跳过第 0 步直接开写 | 把"用户提了同人"当作已授权 | 回退，补做确认 |
| 写出原作名场面的复刻 | 借用越过了"设定层"进了"表达层" | 删掉，改成同一世界观下的新事件 |
| 主角变成工具人 | 没建人物一致性表 | 补表，让 OC 承担推进 |
| 声纹走形 | 声纹栏填了形容词而非语言特征 | 重填为可观察特征 |
