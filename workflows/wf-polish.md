# WF 润色 —— 只动字词句，结构与内容一律不动

> 前置：用户说的是"润色/改改句子/语言再顺一点"，**不是**"改成江南腔"。两者区别很大：
> 改文风走 `wf-rewrite.md`（默认段落级重铸）；润色走本流程（句级、保结构、保顺序、保信息）。
> **判错就出事**：用户只要润色，你却重构成江南腔，等于擅自改了他的文章。

## Step 0 · 定级确认（一句话问清）

若用户表述含糊，直接问一句：**"是只理顺语言（不动内容），还是连写法一起改？"** 得到答复再动手，不要猜。

## Step 1 · 病灶扫描（只诊断，不改）

```bash
python scripts/audit_style.py out/原文.md --json
```

必扫的四类病灶，逐段标出位置：

| 病灶 | 检索/判断方式 | 是否属于润色范围 |
|---|---|---|
| AI 腔虚词 | `不禁 / 一丝 / 一抹 / 仿佛在诉说 / 五味杂陈 / 不由自主` | ✅ 改 |
| 长句超载 | 单句 >60 字且含 3 个以上逗号 | ✅ 拆 |
| 动词弱化 | "进行了一次…""对…做出了…" | ✅ 换实动词 |
| 结构问题（缺钩子、无变化、视角乱） | 人工判断 | ❌ **不归润色管，写进报告让用户决定** |

**结构性病灶只能在报告里提，不能顺手改。** 一改就是重写，越权。

## Step 2 · 三类手术（只做这三种）

1. **删虚词**：把"不禁""不由自主""一丝"删掉，句意通常更硬。删完读一遍，若语气变硬过头，再补一个具体动作而不是补回虚词。
2. **拆长句**：>60 字的句子在第二个转折处断开，断点优先选在"但是/可是/结果/于是"之前。**不做短句化改造**——那是风格改写，不是润色。
3. **换实动词**：名词化表达还原成动作（"对门进行了关闭" → "关上门"）。

**禁止事项**：调换段落顺序、增删情节、改台词内容、改人物称谓、把叙述句改成对话——这五项都属改写范畴。

## Step 3 · 保意核对

```bash
python scripts/diff_style.py out/原文.md out/润色后.md
```

要求：

- 「保意核查」里**数字串零变更、引号台词全部保留**；
- 字数变化在 **±15% 以内**（润色不该大改篇幅）；
- 反推级别应为 **L1**。若输出 L2/L3，说明你改过头了，回头收敛。

## Step 4 · 交付

正文 + 改动清单（三类手术各改了几处）+ 一行说明"结构性病灶：有/无（若有，列出来但不改）"。

## 常见失败模式

| 症状 | 病根 | 处方 |
|---|---|---|
| 用户说"你把我文章改没了" | 越权做了结构改写 | 只保留 Step 2 三类手术，其余回退 |
| 润完比原文还啰嗦 | 用解释性短语替换了虚词 | 删就删干净，不要"换个说法解释一遍" |
| 全文句长都变短了 | 做了短句化 | 回退，只拆 >60 字的超载句 |
| 台词被"顺"过了 | 把口语台词改成书面语 | 台词只删语气赘词，不改内容与语序 |
