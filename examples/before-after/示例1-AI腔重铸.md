# 改写前后对照 · 示例 1

> 自撰示例，演示 L2 段落级重铸的典型手术。左侧为典型的"AI 腔"文本，右侧为按本 skill 规则重铸的版本。

## 原文（AI 腔）

> 夜色如墨，寒风凛冽。少年独自站在空旷的操场上，心中五味杂陈。他想起白天发生的事情，不禁握紧了拳头，眼中闪过一丝坚定的光芒。
> "我一定要变强！"他在心中暗暗发誓。青春就像一场盛大的烟火，虽然短暂，但总要绽放一次。

**体检**：四字成语连开、情绪直告（五味杂陈）、负向清单 4 处（不禁/一丝/眼中闪过/暗暗发誓）、通用比喻（烟火）、节奏均匀、感叹号滥用。

## 改后（L2 段落级重铸）

> 晚自习的铃声早就响过了，操场上一盏灯都没有，风把看台上的塑料袋吹得哗啦响。他把白天那张排名表又掏出来看了一遍，纸角已经卷了，上面第七十三名的位置被手指磨得发灰。
> 他把纸叠好，塞回口袋，把拳头松开，又握上。
> 明天五点半，操场见。

**手术明细**：

| 动作 | 依据 |
|---|---|
| "夜色如墨，寒风凛冽" → 具体时刻+具体声音（铃声/塑料袋） | 03 意象具体化、02 禁四字格连开 |
| "心中五味杂陈" → 反复看排名表+纸角卷边 | 06 情绪翻译表 |
| "眼中闪过一丝坚定的光芒" → "松开，又握上" | 03-A 负向词 + 身体域直给 |
| "我一定要变强！…烟火" → "明天五点半，操场见" | 06 金句公式（具体物+反常关系）；感叹号清除 |
| 三段 → 三拍（铺陈/短段收/冷拳） | 02 呼吸、08 冷拳位 |
