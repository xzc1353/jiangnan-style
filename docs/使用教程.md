# 使用教程 · 从零开始

> 这份文档写给**第一次用的人**。不需要懂编程，不需要懂 AI 术语。
> 从头读到第 3 节就能用起来；后面的部分当手册查。

---

## 0. 它到底是什么

一句话：**它是一个"写作教练 + 改稿机"**，专门针对江南那一路的中文小说腔调。

你可以把它当成一个懂行的朋友，能做四类事：

| 你想干的事 | 它怎么做 |
|---|---|
| 从零写一段 | 按江南的套路给你写（不是抄，是照着规律写新的） |
| 把自己的文章改成这个味儿 | 先体检，再动手改，改完给你一份"哪里动了、哪里没动"的对照单 |
| 判断"这段像不像" | 只打分、只指出问题，不动你的一个字 |
| 帮你挑毛病 | 用 12 个数字量一遍，再给三条最该改的 |

**它不能做的事**（先说清，省得你期待错）：

- 不能替你写出长篇小说的构思。它能写文字，故事还得你自己想。
- 不能保证写得像江南本人。它是"接近"，不是"复刻"。
- 不能给你江南的原著原文，也不能帮你把原著内容搬进你的文章里（这是版权红线，见第 9 节）。

## 1. 三种用法，按你的情况选一种

### 用法 A：装上它，直接说话（推荐，最省事）

装好之后你什么都不用敲，用中文说话就行：

> 「用江南的文风写一个雨夜里的告别，八百字左右。」
>
> 「把这段改成江南腔：〔粘贴你的文章〕」
>
> 「这段像不像江南？帮我看看问题在哪。」

AI 会自动认出来该走哪条流程。**这是最推荐的方式**，因为七个流程的细节（先体检再改、改到什么程度、什么不能动）都由它内部执行，你只管说人话。

装法见第 2 节。

### 用法 B：不装，直接把文件夹丢给 AI

如果你用的是别的 AI 工具（Claude、Cursor 等），把 `SKILL.md` 和 `references/` 文件夹一起发给它，说一句：

> 「按这个 SKILL.md 的规则帮我写 / 帮我改。」

它读得懂，因为整个项目就是按"给 AI 读"的格式写的。

### 用法 C：只用脚本，不碰 AI

如果你只想量化一下自己的文章，不进 AI，直接跑脚本（需要电脑装了 Python 3.9 以上）：

```bash
python scripts/audit_style.py 我的文章.txt
```

它会输出 12 个数字和一段判定。怎么读这些数字见第 5 节。

## 2. 安装（就一步）

### 情况一：你用 WorkBuddy 或 Claude Code

把 `jiangnan-style` 这个**文件夹整个**放进这个位置：

**Windows**

```
C:\Users\你的用户名\.workbuddy\skills\jiangnan-style
```

**macOS / Linux**

```
~/.workbuddy/skills/jiangnan-style
```

放对的标准：放完之后，路径应该是 `...skills/jiangnan-style/SKILL.md` 这样的结构。**注意别套两层**（`skills/jiangnan-style/jiangnan-style/SKILL.md` 是错的）。

放完重启一下对话窗口，就生效了。你不放心的话，可以问一句「你现在有哪些技能」，它应该能报出 `jiangnan-style`。

### 情况二：你想先看看、不装

不用装也能用：直接跑脚本（用法 C），或者把文件夹发给 AI（用法 B）。

### 关于"语料"（可选，大多数人不需要）

这个项目里有个 `corpus/` 文件夹，是放**你自己的电子书原文**的地方，用来做两件事：一是统计江南的真实写作数字（已经做好了，结果在 `assets/schemas/thresholds.json`），二是检查你的产出有没有和原著撞句子。

**发布版里没有这个文件夹**，因为里面是别人的书，不能传播。你需要吗？

- 只是想让 AI 帮你写/改 → **不需要**
- 想自己检查"我写的有没有抄到原著" → 需要，而且得你自己有合法的电子书文件

## 3. 七个场景，照着说就行

### 场景 1：从零写（最常见）

**你说**：「用江南的文风写一个〔什么样的人〕在〔什么场合〕〔做什么〕，〔多少〕字。」

例：
- 「用江南的文风写一个刚被队里淘汰的少年，在雨天的训练馆里收拾东西，一千字。」
- 「写个开头，主角是个在食堂打工的大学生，第一天上班，六百字。」

**它会做**：先问你缺的信息（最多问两个问题），然后定骨架 → 分镜 → 写 → 自检 → 交给你。

**你要留意的**：如果它写出来"每段都很短、每段都像金句"，那是用力过猛，直接说「太碎了，段落合并一下，句子别都这么短」。

### 场景 2：把你写的东西改成这个味儿

**你说**：「把这段改成江南腔：〔你的文章〕」

**它会做**（这是重点，跟一般 AI 不一样）：
1. **先体检**你的原文，算出 12 个数字
2. **问你要改多狠**（三个档：只调句子 / 重写表达但保留内容 / 整篇重来）
3. 按档动刀，**每改一段就核对一次"意思有没有变"**
4. 交给你一份对照单：哪些维度变了、数字有没有被改掉、台词有没有丢

**为什么这个顺序重要**：直接让 AI"改写成江南风"，它经常顺手把你的内容也改了——把"三年前"改成"很久以前"，把"7 个三分球"改成"几个三分球"。这个流程专门防这个。

### 场景 3：接着往下写

**你说**：「接着这段往下写五百字：〔上文〕」

**它会做**：先把你上文的"指纹"锁下来（用第几人称、怎么称呼主角、句子多长、多碎），然后接着写，写完还要核对有没有走形。

**为什么**：续写最容易出的问题不是写得不好，是"读起来像换人写的"。

### 场景 4：只打分，不改文

**你说**：「这段像不像江南？给我个诊断，别改。」

**它会做**：机器量 12 个数字 + 人工按 9 个维度打分，然后给你**三条最该改的地方**（带具体位置和改法）。

**它绝对不会**：顺手把你文章改了。因为你要的是判断，它改了你就没有基准了。

### 场景 5：轻度润色（小心别和场景 2 搞混）

**你说**：「帮我润色一下，把句子理顺，内容别动。」

**它会做**：只干三件事——删虚词、拆太长的句子、把"进行了XX"换成实在的动词。

**它不会**：调段落顺序、加情节、改台词。因为那是场景 2 的活。

> ⚠ 这两个场景的区别很重要：你说"润色"，它只修语言；你说"改成江南腔"，它会重写表达。**说错一个词，结果差很远。** 如果它拿不准，会反问你一句。

### 场景 6：先出大纲

**你说**：「我想写个中篇，先给我个大纲。」

**它会做**：一句话内核（谁想要什么、必须失去什么）→ 三个定调问题 → 分卷分章表 → 伏笔账本。**不写正文。**

**为什么先要这个**：长篇写着跑偏，基本都是因为开写前没定"这一卷要失去什么"。

### 场景 7：写同人（默认关闭，需要你确认）

**你说**：「写个龙族同人，路明非和绘梨衣……」

**它会先弹四行合规确认**，问你同不同意"非商用、标注出处、不冒充原作"。

**为什么这么麻烦**：同人是法律灰区，写之前把边界说清楚，比写完被追责好。你回复「确认」它就开写。

## 4. 五个脚本各干什么（不想敲命令可以跳过）

| 脚本 | 一句话作用 | 什么时候用 |
|---|---|---|
| `audit_style.py` | 给文章量 12 个指标，判断"像不像" | 写完想看看达标没有 |
| `diff_style.py` | 对比改前改后，看哪个维度动了、有没有改掉事实 | 改完稿想留个记录 |
| `overlap_check.py` | 查你的文章有没有和原著撞句子 | 要发布前自查（需要本地语料） |
| `extract_epub.py` | 把 epub 电子书转成纯文本 | 你想自己建语料库 |
| `add_reference.py` | 加一个新的题材/体裁模板 | 想写新类型（比如武侠） |

最小用法（在项目文件夹里打开命令行）：

```bash
# 量一篇
python scripts/audit_style.py 我的文章.txt

# 量一整个文件夹（每章都量）
python scripts/audit_style.py 章节文件夹/

# 要机器可读的格式（给程序用）
python scripts/audit_style.py 我的文章.txt --json

# 改前改后对比
python scripts/diff_style.py 原稿.txt 改后.txt

# 查重（需要本地语料）
python scripts/overlap_check.py 我的文章.txt --corpus corpus/source/
```

**加 `--strict` 会变严格**：发现事实被改动就直接报错退出（适合自己给自己把关）。

## 5. 怎么读那份体检报告（最重要的一节）

脚本跑完会输出这样一段：

```
我的文章.txt  (汉字 879 / 段 19 / 句 26)
  M1_avg_sentence_len                21.88
  M2_short_sentence_ratio            0.4545
  ...
  判定: 偏离容忍区间 3 项（...），建议定点重写。
```

### 12 个指标说人话

| 代号 | 名字 | 说人话 | 江南的目标值 |
|---|---|---|---|
| M1 | 平均句长 | 一句话平均多少字 | **23–29 字** |
| M2 | 短句占比 | 短句（<12 字）占多少 | 21%–33% |
| M3 | 单句成段比 | 有多少段落只有一句话 | **30%–45%** |
| M4 | 对话行占比 | 有多少段落里有对话 | 42%–66% |
| M5 | 对话段长 | 带对话的段落平均多长 | 41–59 字 |
| M6 | 比喻密度 | 每千字几个比喻 | 1.6–3.2 个 |
| M8 | 第一人称指数 | "我"字用了多少 | 0.29–0.83 |
| M9 | 冷拳率 | "铺垫完突然来一记短句"的频率 | 0.6%–3.4% 的段落 |
| M10 | 情绪标点 | 每千字几个 ？ ！ … | 9–20 个 |
| M10b | 感叹号 | 每千字几个 ！ | 2–6 个 |
| M11 | 四字格 | 每千字几个成语式四字词 | 5–10 个 |
| M12 | 「的」字 | 每千字几个"的" | 41–49 个 |

> 这些数字不是谁拍脑袋定的，是从 846 万字真实语料里统计出来的中间区间。M12 是最反直觉的：「的」字密度 41–49/千字，差不多**每 22 个字就有一个"的"**。很多人的文章"看着不像"，就是因为"的"用太少——句子太紧、太干净。

### 三条判读原则（避免误判）

**第一条：短文章不要逐项对表。**

1500 字以下的文本，M2（短句占比）、M9（冷拳率）这类"按段落算百分比"的指标会剧烈波动。800 字的文章里打两记冷拳，M9 就 10% 了；而长篇里同样两记只有 1%。

→ **正确做法**：短文章只看方向（是不是全篇都短句？是不是一个冷拳都没有？），不要盯着百分比。要严格对表，请拿整章（3000 字以上）来量。

**第二条：不达标不等于写得差。**

指标只能说明"和江南的统计特征像不像"，不能说明"写得好不好"。一篇指标全绿的文章完全可能很难看。

**第三条：先看最离谱的那一两项。**

报告会列出所有偏离项。**不要一次改 10 项**，挑偏离最远的 1–2 项改，改完再量。一次改十项的结果通常是改成四不像。

## 6. 完整实战演示（真实跑出来的）

### 第 1 步：一份典型的"AI 腔"原稿

```
李明站在空荡荡的篮球馆里，内心充满了难以言喻的失落。他不禁回想起三年前第一次踏进这里的情景，那时候他还是个充满希望的少年，而如今一切都变了。他的心中五味杂陈，仿佛整个世界都在这一刻抛弃了他。他深深地叹了一口气，转身离开了这个承载着他青春记忆的地方，泪水模糊了他的双眼。
```

### 第 2 步：体检

```bash
python scripts/audit_style.py 原稿.txt
```

```

  M2_short_sentence_ratio            0.0       ← 一个短句都没有（目标 21–33%）
  M3_single_sentence_para_ratio      0.0       ← 只有一段（目标 30–45%）
  M4_dialogue_line_ratio             0.0       ← 没有对话（目标 42–66%）
  M6_simile_per_kilo                 8.06      ← 比喻密度 3 倍超标（目标 1.6–3.2）
  M9_cold_punch_rate                 0.0       ← 没有冷拳
  M10_punct_per_kilo                 0.0       ← 没有问号感叹号省略号
  M11_fourchar_per_kilo              0.0       ← 没有四字格
  M12_de_per_kilo                    56.45     ← "的"太多（目标 41–49）
  判定: 偏离容忍区间 10 项
```

**翻译成人话**：一大段话说完，没有一个短句、没有分段、没有对话、没有停顿，全靠"内心充满""五味杂陈""仿佛世界崩塌"这类词硬顶情绪。

### 第 3 步：改写

```
篮球馆十点熄灯，他坐在看台上没走。

灯一盏一盏灭，最后只剩下安全出口那点绿光。他把手插在裤兜里，摸到一枚一元硬币，边都磨圆了。

三年前他第一次来这儿，穿的还是新球鞋，鞋底在地板上擦得吱吱响。那天他投进了七个三分球，最后一个是从半场扔的。

现在他连球都不带了。

「还不走？」看门的老头在门口喊，手电筒的光扫过来，在他脸上停了一下，「你这年纪，练不出来的，回家吧。」

他站起来，膝盖响了一声。

「明天还来吗。」老头又问，语气像是在问天气。

「来。」
```

```

  － 原文无引号台词

```

### 第 5 步：怎么读这份对照单

- **改对了**：有了段落、有了短句、有了对话、比喻从 3 倍超标降到接近正常。情绪从"内心充满失落"变成了"摸到一枚硬币，边都磨圆了"和"膝盖响了一声"——这是动作，不是宣告。
- **改过头了**：句长从 31 掉到 15，比江南的 23–29 短太多；「的」字从 56 掉到 27，低于目标 41–49。**这说明我改得太碎、太干净了**，是常见的新手偏差（越改越短越利落，反而失真）。
- **保意核查通过**：数字没变、没有台词丢失。注意最后那行"中文数字无法识别"——这是脚本的已知盲区，得自己看一眼。

**这一步的教训**：改写不是"越短越好、越利落越好"。江南的句子比你以为的长，比你以为的啰嗦。

## 7. 常见问题

**问：写出来不像怎么办？**

先别急着让它重写。按顺序查三件事：
1. 句子是不是全都很短？（看 M1，低于 20 就是都太短了）
2. 是不是没有分段？（看 M3，低于 20% 就是段落太长）
3. 是不是"每段都像高潮"？（看 M9，超过 5% 就是冷拳太多了）

告诉它具体是哪一项不对，比说"不像"有效十倍。

**问：能不能写得像江南本人写的，让人看不出来？**

产品目标就是这个（"模仿"），但要说实话：
- 文风本身（句式、节奏、用词习惯）**不受著作权保护**，学着写是合法的。
- 但**不能标注成江南本人作品**，不能拿去冒充原作者投稿。这是欺诈，不是风格问题。
- 具体能达到多像，现在还没做盲测（这是下一个版本 v1.1 要做的事）。目前的定位是"像这个路数"，不是"能骗过粉丝"。

**问：能商用吗？**

你写的原创内容，你自己用没问题。但：
- 不要包装成江南的作品卖。
- 写同人（用他的角色和世界观）不能商用，需要权利人授权。
- 本项目是 MIT 协议，工具本身随便用。

**问：会抄到原著吗？**

项目做了三层防护：仓库里不放任何原文、提供 `overlap_check.py` 查重、交付前要求跑一遍（红线是"连续 15 字不得与原著重合"）。但**机器查重不能保证 100%**，正式发布前你自己也要看一遍。

**问：为什么它老问我问题，不能直接写？**

只在信息不够时问（最多两个问题）。你要是不想被问，开头就把五个要素说全：**谁、在哪、要干什么、什么基调、多少字**。

**问：能写英文吗？**

不能。这是给中文设计的，所有指标（句长、四字格、「的」字密度）都是中文口径。写英文它会输出很怪的东西。

**问：能写诗吗？能写剧本吗？**

能写，但会失真。这些指标是从**小说**里统计的，诗歌和剧本的句长、分段结构完全不同，硬套会得到"很怪的小说腔"。

**问：它跟我直接跟 AI 说"模仿江南写"有什么区别？**

三个区别：
1. 它有**量化标准**（12 个数字），不是凭感觉说"像不像"
2. 它有**流程约束**（改写必须先体检、必须保意核查），不是一次性生成
3. 它有**红线检查**（查重、同人确认），不会给你惹麻烦

**问：文件好多，我需要全看吗？**

不需要。你只用记住 `SKILL.md` 是总规则、`docs/使用教程.md` 是这份文档、`references/` 是给 AI 查的手册。

**问：`corpus/` 是空的，是不是坏了？**

不是。发布版故意不放原文（版权原因）。没有语料时，除了"查重"功能不可用，其他都正常工作。

**问：数字对不上怎么办？**

如果你手上有旧版跑出来的报告，跟本文档的数字差很多——**以 `references/style/09-dna.md` 的最新表为准**。v1.0.0 曾有一个断句 bug（把"每段字数"当成"平均句长"），v1.0.1 已修复并重新标定。

## 8. 术语表（把黑话翻译成人话）

| 术语 | 人话 |
|---|---|
| **skill / 技能** | 一个给 AI 的说明书文件夹，装上它 AI 就会做这类活 |
| **审计 / 体检** | 用脚本给文章量 12 个数字 |
| **阈值 / 目标区间** | 江南真实语料里这些数字的常见范围 |
| **冷拳** | 前面长长铺垫一段，然后突然来一句极短的话（"他还没赢过。"）收住 |
| **单句成段** | 一个段落里只有一句话 |
| **意象域** | 比喻从哪个领域取材（食物、机械、天气、宗教……） |
| **指纹** | 一篇文章自己的数字特征，续写时要对得上 |
| **L1 / L2 / L3** | 改稿的三档力度：只改句子 / 重写表达 / 整篇重来 |
| **保意核查** | 检查改写有没有把事实、数字、台词改掉 |
| **语料** | 用来统计和查重的原始小说文本 |
| **标定 / calibrate** | 从语料里统计出那 12 个数字的合理范围 |

## 9. 红线（这些别做）

1. **不要把原著全文塞进仓库或发给别人**。语料只能在自己电脑上用来统计和查重。
2. **不要把你的产出标注成江南本人作品**。
3. **同人不要商用**，不要投稿变现。
4. **不要用它的输出去冒充原作者**参加比赛、投稿、签约。
5. 产出里**连续 15 字不得与原著重合**。发布前跑一次 `overlap_check.py`（有语料时）。

文风不受保护，**具体表达受保护**。这条线是这套东西存在的前提。

## 10. 三分钟速查卡

```
想写新的         → 「用江南文风写〔谁〕在〔哪〕〔干什么〕，〔多少〕字」
想改现有的       → 「把这段改成江南腔：〔文章〕」
想接着写         → 「接着这段往下写〔多少〕字：〔上文〕」
只想要诊断       → 「这段像不像江南？只诊断，别改」
只想理顺语言     → 「帮我润色，内容别动」
想先搭结构       → 「先给我个中篇大纲」
写同人           → 会先弹合规确认，回「确认」才开写

自己量一遍       → python scripts/audit_style.py 文件.txt
改前改后对比     → python scripts/diff_style.py 原稿.txt 改后.txt
发布前查重       → python scripts/overlap_check.py 文件.txt --corpus corpus/source/

数字不对怎么办   → 先看 references/style/09-dna.md 的阈值表
写出来不像怎么办 → 查 M1（句长）→ M3（分段）→ M9（冷拳）三项
```
