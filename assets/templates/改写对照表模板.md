# 改写对照表模板

> L1/L2 改写逐段填写；L3 按信息点清单填写。交付时随 `rewrite/04-diff-report.md` 一起给出。

## 逐段对照

| # | 原文 | 改后 | 手术动作 | 保意核查 |
|---|---|---|---|---|
| 1 | [原句] | [改句] | A类套话清除（"不禁"→动作） | 信息点①②保留 ✓ |
| 2 | [原段] | [改段] | E类节奏重排（抽短句成段） | 信息点①③保留 ✓ |
| … | | | | |

## 汇总栏

```
手术级别：L_
信息点总数：__  保留：__  损耗：__（逐条列损耗理由）
专名核对：全部保留 ✓/列出例外
指标变化：M1 __→__  M2 __→__  M3 __→__（audit_style 前后对照）
红线：overlap_check PASS/FAIL（FAIL 项列出）
风险提示：[至少一条，没有就写"无，但请注意……"]
```

## 使用纪律

1. 每段改完立刻填行，不许写完全篇再补表（补的表会撒谎）。
2. "手术动作"栏只许用 `03-ai-tells.md` 的分类编号 + 一句话说明。
3. 保意核查打 ✗ 的行不许进入交付。
