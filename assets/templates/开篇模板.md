# 开篇模板 —— 四种进入方式

> 配合 `style/01-skeleton.md` 开篇四式。方括号为占位符。全部为自撰模板，非原作引用。

## 式 1 · 场景切

```
[时间状语]，[人物]在[地点][正在做的具体动作]。
[一个反常细节：与动作/环境矛盾的具体物或声音]。
[第一句对话或内心短句，引出反常的原因线索]。
```

示例节奏：
> 十一月的最后一夜，陈舟在天台上给一辆根本没有电的自行车打气。
> 打气筒每压一下，楼下便利店的灯就闪一下。
> 他数到第七下的时候，决定不数了。

## 式 2 · 对话切

```
"[半截对话——从话题中段切入]。"[说话人动作拍]
"[对方答非所问或抬杠]。"
[一段锚定：这是哪里、几点、两个人是什么关系——只用一句]
```

要点：读者从对话裂缝里猜前情，锚定段放在第 3–4 行，不许放开头。

## 式 3 · 回忆切

```
[现在时态的一个动作]。
[物件触发：他看见/摸到/闻到 X，X 是旧物]。
[≤200 字闪回：有时间地点的一个具体瞬间，结束在当时的对话或动作]。
[回到现在：一个动作把"我"捞回来，例如把东西放回原处]。
```

要点：闪回必须有具体瞬间，禁止情绪总结式回忆。

## 式 4 · 悬念切

```
[异常结果或倒置陈述，一句话，越具体越好]。
[回到 X 小时/X 年前，过程开始]。
```

示例节奏：
> 球鞋在柜子顶上放了三年，鞋带还系着那个死结。
> 那个结是高一开学第一天系的。

## 通用自检

- 第一句删掉"那是一个/记得那年/很久很久"开头法。
- 前 300 字内必须出现：一个人物 + 一个正在进行的动作 + 一个具体名词。
- 禁止天气开场（"那天下着雨"），天气只能作第二句以后的配角。
