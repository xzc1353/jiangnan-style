# 章节模板 —— 起·承·转·钩

> 配合 `style/01-skeleton.md`、`adapters/forms/serial.md`。自撰模板。

## 骨架（3000–6000 字/章）

```
【起】钩子开场（200–400 字）
    - 开篇四式选一（见 开篇模板.md）
    - 位置：上一章钩子的直接回应，不许跳过冷却期

【承】场景推进 ×2（2000–3500 字）
    - 场景 A（1000–1800 字）：主线事件推进，至少释放 1 个信息块
    - 场景 B（1000–1800 字）：人物关系变化，允许一段低气压喜剧回血（07）

【转】变化时刻（400–800 字）
    - 本章的"一次变化"在此落地：信息被证实/关系被改变/决定被做出
    - 可用一次"忽然"扳机 + 一个冷拳

【钩】章末钩子（≤100 字）
    - 三型轮换（悬念/反转/余味），与上一章不同型
    - 最后一行删掉一半字数后更有力才合格
```

## 每章自检表

- [ ] 删掉整章，主线缺了什么？（答不上→重写）
- [ ] 信息块挂在动作上了吗？
- [ ] 对话轮有推进吗？
- [ ] 冷拳 ≤2 次且落在情绪位？
- [ ] 章末钩子与上一章不同型？
- [ ] 设定说明没有超过 2 连续句？

## 伏笔登记

本章若埋伏笔 → 立刻登记 `assets/templates/伏笔账本.md`：埋点章节、内容摘要、预定回收章、状态（待回收/已回收/已放弃）。
