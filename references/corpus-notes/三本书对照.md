# 分册对照：三本书的风格一致性检验

> 数据来源：本地 `corpus/source/` 全量，按书分组后**按章节取中位数**（不取总平均，避免长篇单章权重过大）。
> 抽样 1613 个有效章节文件，合计 846.8 万汉字。本文件只记统计结论，不含任何原文。

## 总表（中位数）

> ⚠ **v1.0.1 重标定后重算**（断句 bug 修复，见 quant-findings.md 顶部说明）。

| 指标 | 缥缈录（271章 / 102万字） | 合集25册（991章 / 486万字） | 龙族 Ⅰ-Ⅴ（351章 / 258万字） | 极差 |
|---|---|---|---|---|
| M1 平均句长 | 23.14 | 25.31 | 28.42 | 5.3 字 |
| M2 短句占比 | 29.1% | 28.1% | 23.5% | 5.6 pt |
| M3 单句成段比 | 38.2% | 37.0% | 43.8% | 6.8 pt |
| M4 对话行占比 | 57.8% | 54.2% | 48.8% | 9.0 pt |
| M6 比喻密度 | 2.20 | 2.24 | 2.51 | 0.31 |
| M9 冷拳率 | 2.4% | 1.9% | 1.5% | 0.9 pt |
| M10b 感叹号 | 3.29 | 3.76 | 3.07 | 0.69 |
| M12「的」字 | 44.27 | 44.26 | 45.16 | 0.90 |

## 结论一：指纹稳定，跨作品可迁移

M12（「的」字 44–45/千字）、M10b（感叹号 3.1–3.8/千字）两项极差极小；M3 与 M9 极差也不大（6.8 pt / 0.9 pt）。这说明**"单句成段 + 低频冷拳 + 稳定的『的』字密度"是作者级常量，不是单部作品的局部风格**。

→ 对 skill 的意义：`thresholds.json` 用三本合并标定是合理的，不需要按书分档。模仿目标应是这组常量。

## 结论二：差异集中在两个维度，且方向一致

按"古装 ↔ 现代"排列（缥缈录 → 合集 → 龙族），呈现单调趋势：

- **M2 短句占比 29.1% → 28.1% → 23.5%**（递减）
- **M4 对话行占比 58% → 54% → 49%**（递减）
- **M1 平均句长 23.1 → 25.3 → 28.4 字**（递增）

即：**越接近现代都市题材，句子越长、短句越少、对话越少；越古风，句子越碎、对话越密。**

这解释了为什么"写校园要更口语更碎、写九州要更铺陈"——不是感觉，是数据趋势。

→ 对 skill 的意义：`adapters/genres/` 的权重调整有了量化依据。写现代题材时 M1 应向 28–30 靠、M4 可低至 49%；写东方奇幻时 M1 向 23 靠、M4 应提到 55% 以上。

## 结论三：比喻密度与题材无强关联

M6 三本分别为 2.20 / 2.24 / 2.51，**龙族最高**。打破"古风才多用比喻"的直觉——现代校园题材的比喻密度反而略高，因为日常物象（食堂、球鞋、试卷）更容易就地取喻。

→ 对 skill 的意义：不要因为写现代题材就降低比喻预算。`style/03` 里的"比喻取材于生活半径"比"比喻密度"更关键。

## 已知偏差

1. **合集与单行本重复**：合集 25 册内含龙族 Ⅰ-Ⅴ、缥缈录，与另两个文件集存在内容重叠，合并标定时龙族/缥缈录段落实际被计了约两遍。偏差方向：**使句长与段落结构的分布向长篇倾斜**，但中位数指标受影响较小（已验证三本中位数彼此接近）。
2. **章节切片不均**：掌阅导出的龙族含封面、版权页等极短文件，已用 `>50 字` 过滤，仍有少量残页。
3. 本表为**中位数**，与 `quant-findings.md` 里的**全局 P25/P50/P75** 口径不同，两处数字不可直接混读。

## 复现方式

```bash
python scripts/audit_style.py corpus/source/ --calibrate -o assets/schemas/thresholds.json
```

分册数据需按书名前缀分组后逐章 `compute_metrics` 取中位数；脚本未内置分册模式，如需重跑请照本节口径自行分组。
