# 红线 · 版权（任何模式生效）

## 判定标准：什么算"抄"

1. **文字重合**：产出与任何已出版文本存在 ≥15 连续字（归一化后）的相同片段 → 抄。用 `scripts/overlap_check.py` 机械判定。
2. **桥段照搬**：具体情节链（同一组事件按同一因果顺序重演），即使全部换了措辞。
3. **专名系统性复用**：非同人模式下大量使用原作专名（人名/组织/设定词）——同人模式除外（见 fanfic-policy）。
4. **结构复刻**：逐章复刻原作的结构骨架。

## 引用规则（非虚构场景，copywriting.md）

- 评论文中引用原作：≤3 处、每处 ≤25 字、必须可核对、必须标注出处。
- 超限就改为转述——转述不需要逐字对应，也几乎不构成侵权风险。

## 交付前固化管理

1. 有本地语料：`overlap_check.py` 必跑，FAIL 不交付；
2. 无本地语料：在交付说明中写明"未做机械查重，请人工核对"；涉及原作设定/桥段近似时主动声明；
3. 同人模式：额外执行 fanfic-policy 的全部前置项。

## 为什么这条线存在

文风不受著作权保护，具体表达受保护。本 skill 的全部价值建立在"抽象规则 + 原创示例"上，一旦把表达抄进来，整个项目的合规立足点就塌了。
