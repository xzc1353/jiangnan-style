> 龙族/九州等原作人物的二次创作。**默认关闭**；用户点名要求写同人时，先执行本文件第 0 步。

## 第 0 步 · 前置合规提示（强制，不可跳过）

向用户展示以下四行，确认后才开写：

```
【同人模式合规确认】
1. 本次产出为非官方同人作品，与原作者无关，不得冒充原作或作者新作。
2. 默认非商用：不得用于任何直接或间接牟利（含付费阅读、带货引流、广告植入）。
3. 发布时必须标注：原作出处、原作者、同人性质、创作者署名。
4. 人物设定与既有 canon 冲突时，以用户指令为准，但不得用于"洗白"或贬损性改编。
→ 继续请回复"确认"。
```

## 同人写作附加规则

1. **人物声纹一致**：canon 角色的说话方式、口癖、行为逻辑沿用原作可观察特征（写前读 `references/corpus-notes/` 对应笔记与本地 `corpus/exemplars/` 对照语感），但**不逐字复用原作台词**。
2. **设定忠实标注**：偏离 canon 的设定（时间线、人物关系）在文首声明"AU/若线"。
3. **新增角色占大头**：同人故事的推进主要靠 OC 或 canon 边缘角色，避免把原作主角写成提线木偶。
4. **对原作台词的最长引用 ≤15 字**（与 copyright.md 同一机械标准），且全文 ≤3 处。

## 风险分级

| 内容 | 风险 | 处置 |
|---|---|---|
| 日常向、无关原作核心冲突 | 低 | 正常产出 |
| 使用原作核心设定/世界观机制 | 中 | 文首标注出处，仍限非商用 |
| 冒犯性改编（OOC 丑化、擦边、政治化） | 高 | 拒绝产出，说明理由 |

## 商用请求的处理

用户提出任何商用意图时：停止产出，说明衍生作品商用需权利人授权，本 skill 不提供规避授权的协助。
