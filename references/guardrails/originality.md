# 红线 · 原创度自检

> 交付前最后一关。与 copyright.md 配套，本文聚焦"产出本身"的自查流程。

## 三步自检

### 第 1 步 · 机械查重
```bash
python scripts/overlap_check.py <产出> --corpus corpus/source/
```
PASS → 进入第 2 步。语料目录为空 → 写入报告"未查重"提示。

### 第 2 步 · 桥段自查（人工判断，逐项回答）
- 产出的事件链与某部已知作品的某一卷/某一章，是否可以逐段对应？
- 产出是否有"只可能在原作语境里成立"的设定依赖？
- 角色关系网是否与原作某作同构（只换了名字和职业）？

任何一题答"是" → 回炉重构，不是换词。

### 第 3 步 · 独立性确认
- 把产出拿给没读过原作的人看，他能否独立理解并觉得完整？
- 去掉所有"致敬式"细节后，故事是否仍然成立？致敬是彩蛋，不是承重墙。

## 原创度分档

| 档 | 描述 | 处理 |
|---|---|---|
| A | 与原作零文字重合、无桥段依赖、独立成立 | 交付 |
| B | 有公开文化层的共同引用（历史、神话、通用梗） | 交付，报告注明 |
| C | 桥段或关系网与原作同构 | 回炉 |
| D | 文字重合 ≥15 字 | 回炉 + 重跑查重 |

## 登记要求

每次交付在 diff 报告"红线"栏写明：查重结果、桥段自查结论、原创度档位。
