# 04 人物法 —— 少年感公式与群像生态

> 数据依据：人称指数 M8 实测目标区 0.29–0.83（第三人称限知为主，第一人称只作穿插）；高频 3-gram 里人名占据显著位置（多部作品主角与四五个配角名同进 Top20），配角戏份权重极高，是"群像生态"的直接证据。样例见本地 `corpus/exemplars/成长顿悟.md`。

## 少年感公式

```
少年感 = 普通（出身/成绩/长相至少一项平庸）
       + 倔强（认定的事不讲道理）
       + 嘴硬（受伤先否认）
       + 自嘲（把惨事讲成段子）
       + 一根筋的善良（关键时刻不计算）
```

五个要素按需组合，但**嘴硬 + 自嘲**是标识性配对：角色用玩笑话包裹真实动机，读者要能拆开玩笑看到底。

自撰示例：
> "我就是想看看海。"他说。其实他连游泳都不会，而且那张车票花掉了他半年的零花钱。这件事他打算烂在肚子里。

## 主角规则

- 主角必须**输得起场面**：开局让他在最在意的领域平庸（学习、力气、出身任选），他赢的方式永远是"非天才路线"。
- 主角的成长以"代价"计价，不以"顿悟"计价：每次变强都要明码标价失去什么。
- 禁止全知全能时刻；主角可以聪明，但必须聪明在具体的事上。

## 配角规则（群像生态）

1. **出场自带三件套**：来历（一句就够）、口头禅或标志性动作、私心。三件套缺一的配角降级为背景板，干脆不给戏份。
2. **配角有自己的时间线**：他们不只在主角需要时出现——让配角在主角不在场时"也过着自己的日子"，用一个细节暗示即可。
3. **反派是另一种主角**：反派的目标在其自己的逻辑里成立，给他一场"如果他是对的"的戏。
4. 师门/班级/团队按**生态系统**写：有食物链、有暗涌、有小团体，不许人人围着主角转。

## 对话中的声音分离

每个主要角色一句可辨识的"声纹"：称呼习惯、句长偏好、口头禅。检验法：删掉说话人标记，能不能靠台词认出是谁。认不出→重写。

## 自检

- 把主角换成配角推剧情，能不能推得动？能→说明配角立住了。
- 全文搜人物名，出场频率第一的是不是主角？不是→视角漂了。
- 反派的动机，能不能用一句不含"坏"字的话讲清？
