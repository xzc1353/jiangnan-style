# 09 风格 DNA —— 可量化指纹

> 本文件定义"像不像"的**度量**。目标区间一栏先用 `--calibrate` 模式对本地语料实测后填入；未标定前审计脚本一律输出 `uncalibrated`，**禁止凭印象填数字**。

## 指标定义（与 `scripts/audit_style.py` 一一对应）

| # | 指标 | 定义 | 计量 |
|---|---|---|---|
| M1 | 平均句长 | 按 。！？… 切分后的平均句字符数（汉字计） | 字 |
| M2 | 短句占比 | 长度 <12 字的句子 / 全部句子 | % |
| M3 | 单句成段比 | 只含 1 句的非空段落 / 全部非空段落 | % |
| M4 | 对话行占比 | 含引号引语的行 / 全部非空行 | % |
| M5 | 对话均长 | 引语平均字符数 | 字 |
| M6 | 比喻密度 | 比喻词（像/好像/仿佛/如同/宛如/好似/恍若）每千字出现次数 | 次/千字 |
| M7 | 比喻取材域分布 | 六域（机械金属/光与火/天气季节/食物烟火/宗教神话/身体）命中占比 | % |
| M8 | 人称指数 | "我" 出现次数 / ("他"+"她"+"它") 出现次数 | 比值 |
| M9 | 冷拳率 | 单句且 ≤10 字、且前一段落 ≥3 句或 ≥40 字的段落占比 | % |
| M10 | 标点温度 | （？！…）合计每千字次数，另报感叹号单独密度 | 次/千字 |
| M11 | 四字格密度 | 被非汉字边界包围的 4 汉字串每千字数（粗代理，见局限） | 个/千字 |
| M12 | "的"字密度 | "的"每千字次数 | 次/千字 |

随笔体（essay mode，`--mode essay`）：M3、M9 权重上调，M4 权重下调；阈值单独一栏。

## 判定规则

- 默认（soft 模式）：超容忍区间的项在报告中列为"偏离项 + 定点改写建议"，**不自动重写**。
- `--strict`：目标区间外的项全部列出，交付前必须归位或书面说明理由。

## 已知局限（写给读报告的人）

- M11 四字格是"4 汉字串"的粗代理，会把普通四字词组计入，只用于横向对比，不做绝对判断。
- M7 取材域靠关键词命中，属启发式；同段多域命中按第一命中计。
- 中文无天然分词，所有长度指标以字符计，未区分词与词组。
- 这些指标回答"**结构上像不像**"，不回答"**内容好不好**"。后者靠 `assets/rubric/style-scorecard.md` 的人工评分。
