# 06 情绪控制 —— 扳机词、冷拳与克制的刻度

> 数据依据：转折扳机词"忽然"实测 0.85 次/千字（全部标志短语中断层第一）；标志短语簇"后来/那天/那一年/那一刻/第一次"合计约 0.35/千字，构成时间跳跃式抒情的基础设施；冷拳率实测 2.6%（段落级）；死亡离别场景高频词集中在"最后/闭上眼/手凉/离开"这类**小动作词**而非情绪词。样例见本地 `corpus/exemplars/死亡离别.md`。

## 情绪的翻译表（铁律 1 的操作版）

| 想表达的 | 不许写 | 要写 |
|---|---|---|
| 悲痛 | "他悲痛欲绝" | 一个反复做的小动作 + 一件具体物 |
| 想念 | "他很想念她" | 触发物（旧物/食物/天气）+ 时间跳跃 |
| 紧张 | "他非常紧张" | 身体域直给：指节、后颈、呼吸（不加修饰） |
| 愤怒 | "他怒不可遏" | 力度失控的动作 + 音量下降（越怒越轻声） |
| 幸福 | "他觉得很幸福" | 此刻一个可保存的感官细节 |

## 冷拳的使用刻度

- 冷拳率实测 2.6%：**每 35–40 个段落出现一次**是自然水位。短句单段的落点必须是"情绪结论"，不是信息结论。
- 冷拳前必须有 ≥3 句的长铺陈蓄力（这是 M9 的定义）；没有蓄力的短句是噪音。
- 千字预算 2–3 次。写完数一遍，超了删最弱的。

## 扳机词系统

- **"忽然"是段落级转折扳机**（0.85/千字）：用在"平稳画面 → 异常"的切换点。注意它是最高频的标志性词，也是最容易滥用 AI 腔的位置——每千字 ≤1 次，不许连续两段都用。
- **时间跳跃四件套**（后来/那天/那一刻/第一次）：用于把"正在发生"切换成"多年后回望"。每次跳跃至少隔 2000 字，否则滥用。
- **"不敢/没敢"**（0.23/千字）：把"他没做"写成"他不敢做"，懦弱感就出来了——这是少年感主角的专用词。

## 金句公式（限量供应）

```
金句 = 具体物（A） + 反常关系（A 对 B 做了 B 不该承受的事）
     [+ 时间维度（很多年以后/后来）]
```

自撰示例：
> 很多年后他还记得那碗面。面早就坨了，他还是吃完了，一滴汤都没剩。

金句预算：千字 ≤1。金句永远放在**段尾或章尾**，不放在段中。

## 高潮与死亡的克制刻度

- 大事件用小反应：死亡场景的动作词表限定在"手凉/闭上眼/最后/离开"级别，**禁用**嚎啕、撕心裂肺、痛哭失声。
- 真正的哭只给一次：全书/全篇最重的那场。之前所有悲伤都漏出来，不许倒出来。
