# 题材适配器 · 都市 / 现代奇幻

> 对应《龙族》式现代舞台：现实城市表皮 + 隐藏的超凡层。配合 style/01-09。

## 世界物料清单

- **空间**：地铁、便利店、旧公寓、天台、快餐店、深夜的街道、机场、写字楼大堂
- **物件**：手机、耳机、外卖、游戏机、信用卡账单、旧照片、家门钥匙
- **超凡层**：血统/异能/秘密组织——**永远藏在日常表皮下面**，从第 3 章起才允许裂开第一道缝

## 权重调整

| style 规则 | 调整 |
|---|---|
| 意象域（03） | 六域全开：宗教神话（组织仪式/宿命）+ 机械金属（装备/载具）+ 食物烟火（日常锚点）三足鼎立 |
| 幽默（07） | 全四层启用；黑色幽默（第 4 层）允许接近高潮使用 |
| 情绪（06） | "忽然"扳机词用在与超凡层的首次接触点，每章 ≤1 |
| 结构（01） | 开篇四式中的"回忆切"与"场景切"优先——超凡设定必须后置 |

## 独有规则

1. **双层世界的咬合**：每个超凡事件都要有日常代价（错过考试、弄丢兼职、手机摔坏）。代价是让读者相信超凡层存在的方式。
2. **组织出场三件套**：一个具体地点、一个不合常理的细节、一个说话不着调的引路人。不许设定倾泻。
3. **超凡能力写感受不写原理**："世界忽然安静了"好过"他的脑波频率改变了"。

## 禁区

- 超凡层不得在前两章主导叙事（日常锚点先行）。
- 能力有代价有上限，禁止无代价开挂。
