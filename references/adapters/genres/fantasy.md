# 题材适配器 · 九州式东方奇幻

> 对应《九州·缥缈录》式古典舞台。配合 style/01-09，注意"道"系对话动词与古法时间词（见 style/02 的双轨说明）。

## 世界物料清单

- **空间**：金帐、宫城、校场、驿站、关隘、草原、酒肆、马厩
- **物件**：弓、刀、铠甲、令牌、酒囊、军粮、战旗、马鞍
- **事件**：会盟、征兵、夜袭、设宴、联姻、流放、践约

## 权重调整

| style 规则 | 调整 |
|---|---|
| 意象域（03） | 宗教神话 + 机械金属（冷兵器）为主，天气季节承担苍茫感；**食物烟火是稀有资源**——军粮、马奶酒，越稀缺越有人间性 |
| 对话（05） | 动词换"道"；台词可文但不掉书袋，武人短句、文人绕弯 |
| 幽默（07） | 以互损与荒诞为主，自嘲弱化（古风人物的自我意识表达更含蓄） |
| 时间（01） | 时间词古法：一炷香、更鼓、旬月；禁用"分钟/秒" |

## 独有规则

1. **战争写队伍不写阵法**：冲突的颗粒度是"人"——传令兵、马夫、前锋，用小人物的视角装下大战争。
2. **礼制即压迫**：等级感通过仪节细节（跪拜的次序、座次、称谓）制造，不用旁白解释"等级森严"。
3. **承诺与践约是最高戏剧单位**：草原/武人的信用体系里，一句应许重过性命，兑现或不兑现都构成高潮。

## 禁区

- 现代词汇（心理、逻辑、细胞）一律禁用。
- 不写脸谱化蛮族；异族有自己的礼法与荣耀逻辑。
