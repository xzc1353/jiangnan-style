# 题材适配器 · 校园 / 青春

> 配合 `style/01-09` 使用。本文件只回答：这个世界里能出现什么、哪些 style 规则在此题材下的权重变化。**不得覆盖 style 规则。**

## 世界物料清单

- **空间**：教室、宿舍、食堂、操场、天台、小卖部、晚自习、校门口的公交站
- **物件**：试卷、涂改带、球鞋、耳机、手机（藏在课本下）、错题本、校服、传纸条
- **事件**：月考排名、运动会、文艺汇演、值日、补课、毕业照、表白与被表白

## 权重调整

| style 规则 | 调整 |
|---|---|
| 意象域（03） | 主体用**食物烟火 + 天气季节**；机械金属只进体育/劳动场景；宗教神话域几乎禁用（除非转入奇幻混合题材） |
| 幽默（07） | 第 1、2 层（自嘲/互损）为主力，吐槽场景密度可上调 |
| 战斗（08） | 无战斗；"竞争场面"（考试发卷、球赛）借用 08 的四拍结构 |
| 对话（05） | 对话行占比可上调至上限 66%，青春题材对话驱动性最强 |

## 独有规则

1. **时间刻度以学期计**：悬念和成长用"月考/期末"做里程碑，不用"升级/突破"。
2. **压抑感来自体制**：排名、家长会、教导处——冲突的对手常是抽象制度，写法是让它通过具体的人（班主任、教导主任）出场。
3. **物证系统**：青春感情的推进靠物件（一张纸条、一副耳机）而非告白台词，物件要有"归还/丢失/转手"三态。

## 禁区

- 不写超自然（除非用户明确要求混合题材，此时改读 urban.md 并注明混合）。
- 不用成人职场词汇（KPI、汇报）污染校园语感。
