# 题材适配器 · 科幻 / 机甲

> 对应《上海堡垒》式近未来舞台。配合 style/01-09。

## 世界物料清单

- **空间**：基地、指挥室、机库、驾驶舱、废墟城市、轨道电梯、通讯频道
- **物件**：操纵杆、头盔、作战服、倒计时、雷达屏、罐头、家书
- **事件**：出击、拦截、失联、撤退、授勋、葬礼

## 权重调整

| style 规则 | 调整 |
|---|---|
| 意象域（03） | **机械金属主导（40%+）**，光与火承担毁灭美学；宗教神话域留给"牺牲与悼亡"专用 |
| 情绪（06） | 死亡离别场景密度天然高，严格执行小动作词表 |
| 结构（01） | 章节钩子以"倒计时/失联"型悬念为主 |
| 对话（05） | 通讯频道对话占高位：短促、代号化、允许被打断 |

## 独有规则

1. **技术为情绪服务**：任何科技细节出现的唯一理由是让人物处境更疼（倒计时让告别变短）。技术说明超过两句即删。
2. **驾驶舱是独白室**：机甲/战机的封闭舱体=角色的孤独高光位，用感官细节（汗、震动、氧气味）写恐惧与决心。
3. **牺牲要有名字**：伤亡不写数字，写名字和一件遗留物（半包烟、没织完的围巾）。

## 禁区

- 不堆参数（型号、当量、马力只许点到）。
- 外敌不做纯怪兽，给它们可理解的行动逻辑。
