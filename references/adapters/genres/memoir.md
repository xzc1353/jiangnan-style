# 题材适配器 · 回忆散文 / 随笔

> 对应"龙与少年游"式第一人称回望文体。**审计用 `--mode essay`。** 配合 style/01-09。

## 世界物料清单

- **空间**：旧居、校园、车站、异乡的城市、深夜的电脑前
- **物件**：旧书、车票、照片、食物、天气、一首歌
- **事件**：离开、重逢、得知某个消息、某个平常的下午

## 权重调整

| style 规则 | 调整 |
|---|---|
| 人称（01/02） | 第一人称强制；叙述距离拉远——"我"讲自己的事像讲别人的事 |
| 情绪（06） | 全文是克制刻度的主场：一件事只许漏一次情绪 |
| 幽默（07） | 自嘲为主，且自嘲对象必须是"当年的自己" |
| 结构（01） | 章节骨架换成"物件/场景 → 蔓延 → 收在当下"三段式 |

## 独有规则

1. **由实入虚，由虚落实**：从具体物件起笔，蔓延到感慨，最后必须**落回一个具体动作**收尾（合上书、关灯、把杯子洗了）。禁止悬在抒情里结束。
2. **时间双层**：过去的"我"和现在的"我"同场出现，两层视角的差异本身就是内容。
3. **感慨要付费**：每一段感慨之前必须有一个可触发的具体事件，无事件不发感慨（无锚抒情 = AI 腔的最大来源）。

## 禁区

- 不写"青春""岁月""成长"这类空转大词，除非正被具体事件嘲讽。
- 不虚构读者无法核实的"人生哲理"，哲理只从自己的事里长出来。
