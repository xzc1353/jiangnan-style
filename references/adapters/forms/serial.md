# 体裁适配器 · 长篇连载

> 配合 style/01-09。连载的核心增量是：**每章末钩子 + 跨章伏笔记账**。

## 节奏预算

| 要素 | 配额 |
|---|---|
| 章节长度 | 3000–6000 字/章（实测 P50 见 quant.json） |
| 章末钩子 | 100% 必配；三型（悬念/反转/余味）轮换，连续两章不重 型 |
| 冷拳 | 每章 1–2 次 |
| 新角色 | 每卷 ≤6 个有名字的新角色 |

## 独有规则

1. **伏笔账本**：用 `assets/templates/伏笔账本.md` 记录每个伏笔（埋点章节/预定回收点/状态）。连载杀手不是写差，是写丢。
2. **卷级呼吸**：每卷（15–30 章）遵循"蓄势→爆发→余烬"三段；卷末章允许整章余烬（大事件后的安静），这是读者回血的必要节奏。
3. **追更友好**：每 3 章至少复现一次核心人物关系快照（通过对话自然带出，不许旁白总结"此前情节"）。
4. **升级要付费**：主角每次变强/得到，当章或次章必须付出代价（伤、失、误会产生）。

## 禁区

- 禁止连续三章纯过渡。
- 禁止为钩子而钩子：章末悬念必须在 2 章内开始兑现。
