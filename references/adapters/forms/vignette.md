# 体裁适配器 · 片段 / 场景速写（≤2000 字）

> 配合 style/01-09。片段是"一个镜头的电影"，检验风格的最佳练兵场。

## 节奏预算

| 要素 | 配额 |
|---|---|
| 冷拳 | 1 次（结尾） |
| 金句 | 0–1 句 |
| 场景 | 1 个，不切换 |
| 人物 | 1–2 个 |
| 对话 | ≤6 轮 |

## 独有规则

1. **单一时刻原则**：只写一个时刻（一顿饭、一站路、一次等待），冲突是时刻内部的（一句话没说出口）。
2. **感官三件套**：全篇至少各一次——一个具体声音、一个气味/温度、一个光线变化。
3. **结尾必收在动作上**：最后一个动作暗示"之后什么都变了/什么都没变"（他把她那份也吃了 / 他把两个人的碗都洗了）。

## 禁区

- 禁止背景交代超过 3 句。
- 禁止心理独白超过 2 句（片段靠画面说话）。
