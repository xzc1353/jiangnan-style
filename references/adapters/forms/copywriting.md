# 体裁适配器 · 非虚构（书评 / 文案 / 推荐语）

> 配合 style/01-09。用江南腔写评论与文案——不是模仿他"评价别人"，而是借他的语言皮肤写我们的观点。**观点必须真实且属于用户**，风格只作用于表达层。

## 权重调整

| style 规则 | 调整 |
|---|---|
| 情绪（06） | 感慨要付费：每个判断配一个书中的具体证据 |
| 意象（03） | 取材域可跨书借用：评机甲小说用机械域，评校园小说用食物域 |
| 对话（05） | 无对话；"引用原作句子"必须 ≤3 处且各 ≤25 字（合规上限，见 guardrails/copyright） |
| 冷拳（06） | 观点句用短句收——"他写的不是龙，是没赶上的那些人。"式 |

## 独有规则

1. **评人不评市场**：聊作品的野心、失败与私人趣味，不写"销量破亿"式通稿腔。
2. **具体压倒抽象**："写到第三章他把主角弄瞎了"好过"作者敢于突破"。
3. **文案的克制**：推荐语 ≤3 句；最后一句必须是具体物或动作，禁止"不容错过"。

## 禁区

- 全文不出现"史诗级""封神""泪目"。
- 不虚构读后感式的假情节；引用必须可核对（引用多且长时提示用户改写为转述）。
